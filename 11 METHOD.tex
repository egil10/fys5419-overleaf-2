\section{Methods}\label{section:methods}

The QAOA pipeline turns a financial dataset into a quantum circuit through a sequence of well-defined steps,
\begin{equation}
    \text{Financial data} \rightarrow (\boldsymbol\mu,\boldsymbol\Sigma) \rightarrow \text{QUBO} \rightarrow \text{Ising} \rightarrow \text{Pauli operators} \rightarrow \text{QAOA}.
\end{equation}
In plain words: we start from daily stock prices, summarise them as an expected-return vector $\boldsymbol\mu$ and a covariance matrix $\boldsymbol\Sigma$, write the portfolio objective as a quadratic cost over binary ``in or out'' decisions (a QUBO), rewrite the same cost in $\pm 1$-spin variables so it becomes a classical magnet (an Ising Hamiltonian), promote each spin to a Pauli-$Z$ operator on a qubit, and finally drive a short tunable quantum circuit (QAOA) whose measurement statistics concentrate on low-cost portfolios. Subsections~\ref{subsec:meanvar}--\ref{subsec:qaoa} develop each arrow in turn. \Cref{subsec:xymixer} develops the constraint-preserving XY-ring mixer that we later benchmark in \cref{subsec:xymixer-results}, \cref{subsec:warmstart} formalises the warm-start initialisation prescription benchmarked in \cref{subsec:warmstart-results}, and \cref{subsec:metrics} fixes the metrics used throughout \cref{section:result}.


\subsection{Mean--variance portfolio optimisation}\label{subsec:meanvar}

For a binary selection vector $\boldsymbol{x} \in \{0,1\}^n$ over $n$ candidate assets, the Markowitz objective \autocite{markowitz1952} is
\begin{equation}
    \min_{\boldsymbol{x}} \left( -\boldsymbol\mu^\top \boldsymbol{x} + \lambda\, \boldsymbol{x}^\top \boldsymbol\Sigma\, \boldsymbol{x} \right),
\end{equation}
where $-\boldsymbol\mu^\top \boldsymbol{x}$ maximises expected return and $\lambda\, \boldsymbol{x}^\top \boldsymbol\Sigma\, \boldsymbol{x}$ penalises portfolio variance. The risk-aversion parameter $\lambda \geq 0$ tunes the trade-off.

A fixed-budget constraint requires exactly $K$ assets,
\begin{equation}
    \sum_{i=1}^{n} x_i = K,
\end{equation}
which we enforce with a quadratic penalty, giving the soft-constrained cost
\begin{equation}\label{eq:Cx}
    C(\boldsymbol{x}) = -\boldsymbol\mu^\top \boldsymbol{x} + \lambda\, \boldsymbol{x}^\top \boldsymbol\Sigma\, \boldsymbol{x} + A \left( \sum_{i=1}^{n} x_i - K \right)^2,
\end{equation}
where $A > 0$ is chosen large enough that the global minimum of $C(\boldsymbol{x})$ satisfies the budget constraint. \Cref{subsec:Asensitivity-results} studies the sensitivity of this calibration empirically.

Returns and their first two moments are estimated from price series $P_i(t)$ via log returns,
\begin{equation}\label{eq:logreturn}
    r_i(t) \;=\; \ln\frac{P_i(t+1)}{P_i(t)},
\end{equation}
\begin{equation}
    \mu_i = \langle r_i \rangle_t,
    \qquad
    \Sigma_{ij} = \langle r_i r_j \rangle_t - \langle r_i \rangle_t \langle r_j \rangle_t,
\end{equation}
where $\langle\,\cdot\,\rangle_t$ denotes the time average across the in-sample window. Estimating $(\boldsymbol\mu, \boldsymbol\Sigma)$ from a single window is a well-known weakness of the Markowitz programme \autocite{hastie}; we accept it here, since the algorithmic question is independent of the estimator.


\subsection{Quadratic unconstrained binary optimisation (QUBO)}\label{subsec:qubo}

QUBO (Quadratic Unconstrained Binary Optimisation) is the standard input format the quantum optimisation literature expects, so the penalised mean--variance cost of \cref{eq:Cx} is rewritten in that shape before anything quantum happens. A QUBO is a quadratic cost over binary variables,
\begin{equation}
    \min_{\boldsymbol{x}\in\{0,1\}^n} C(\boldsymbol{x}) = \sum_i Q_{ii}\, x_i + \sum_{i<j} Q_{ij}\, x_i x_j,
\end{equation}
where the linear terms are absorbed into the diagonal of $Q$ because $x_i^2 = x_i$ for binary variables. Expanding the penalised mean--variance cost~\eqref{eq:Cx} yields
\begin{equation}
\begin{aligned}
    C(\boldsymbol{x}) &= \sum_i \underbrace{\bigl[-\mu_i + \lambda\Sigma_{ii} + A(1-2K)\bigr]}_{Q_{ii}}\, x_i \\
    &\quad + \sum_{i<j} \underbrace{\bigl[2\lambda\Sigma_{ij} + 2A\bigr]}_{Q_{ij}}\, x_i x_j + \underbrace{AK^2}_{\text{const}},
\end{aligned}
\end{equation}
so
\begin{equation}\label{eq:Qcoeffs}
    \boxed{
    \begin{aligned}
    Q_{ii} &= -\mu_i + \lambda\Sigma_{ii} + A(1-2K), \\
    Q_{ij} &= 2\lambda\Sigma_{ij} + 2A \quad (i<j).
    \end{aligned}
    }
\end{equation}


\subsection{Ising Hamiltonian mapping}\label{subsec:ising}

The next step rewrites the same cost in $\pm 1$-spin variables rather than $\{0,1\}$ bits. The reason is purely book-keeping for the quantum step that follows: the Pauli-$Z$ operator that will replace each spin has single-qubit eigenvalues $\pm 1$ by construction, so spins map to qubits with no extra arithmetic. Mapping binary variables to spins via
\begin{equation}
    x_i = \tfrac{1}{2}(1-z_i),\qquad z_i\in\{-1,+1\},
\end{equation}
and substituting into $C(\boldsymbol{x})$ produces an Ising form
\begin{equation}\label{eq:Hz}
    H(\boldsymbol{z}) = \sum_i h_i\, z_i + \sum_{i<j} J_{ij}\, z_i z_j,
\end{equation}
with coefficients
\begin{equation}\label{eq:hJ}
    h_i = -\tfrac{1}{2} Q_{ii} - \tfrac{1}{4} \sum_{j\neq i} Q_{ij},
    \qquad
    J_{ij} = \tfrac{1}{4} Q_{ij} \quad (i<j),
\end{equation}
and an additive constant
\begin{equation}\label{eq:c}
    c = AK^2 + \tfrac{1}{2}\sum_i Q_{ii} + \tfrac{1}{4}\sum_{i<j} Q_{ij},
\end{equation}
chosen so that $H(\boldsymbol{z}) + c = C(\boldsymbol{x})$ for every binary $\boldsymbol{x}$ and its spin image $\boldsymbol{z}$. We keep the constant in the Hamiltonian throughout this report, so the eigenvalues of $H_C$ defined below equal the cost values $C(\boldsymbol{x})$ directly, the same convention as the reference implementation.


\subsection{Pauli operators and the cost Hamiltonian}\label{subsec:pauli}

We follow the standard quantum-computing conventions of \textcite{nielsen_chuang} for single-qubit gates and tensor-product ordering. Promoting each classical spin $z_i$ to the single-qubit Pauli-$Z$ operator on site $i$,
\begin{equation}
    z_i \longrightarrow \hat{Z}_i = I^{\otimes i}
    \otimes Z \otimes I^{\otimes (n-i-1)},
    \qquad
    Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix},
\end{equation}
gives the cost Hamiltonian as the $2^n\times 2^n$ diagonal matrix
\begin{equation}\label{eq:HC}
    \boxed{
    H_C = c\, I + \sum_i h_i\, \hat{Z}_i + \sum_{i<j} J_{ij}\, \hat{Z}_i \hat{Z}_j.
    }
\end{equation}
Every computational basis state $|\boldsymbol{z}\rangle$ is an eigenstate of $H_C$ with eigenvalue $C(\boldsymbol{x})$.

The standard \emph{transverse-field} mixing Hamiltonian drives tunnelling between bitstring states,
\begin{equation}\label{eq:HM-transverse}
    H_M = \sum_{i=1}^{n} \hat{X}_i,
    \qquad
    X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}.
\end{equation}
Two properties make $H_M$ natural. First, $\hat X_i$ flips qubit $i$, so $[H_M, H_C]\neq 0$ and the mixer generates the non-diagonal dynamics QAOA needs to interfere between bitstrings. Second, the ground state of $-H_M$ is the uniform superposition
\begin{equation}\label{eq:plus-state}
    |s\rangle \;=\; |+\rangle^{\otimes n} \;=\; \frac{1}{\sqrt{2^n}}\sum_{\boldsymbol{x}\in\{0,1\}^n} |\boldsymbol{x}\rangle,
\end{equation}
prepared by a layer of Hadamards on $|0\rangle^{\otimes n}$ and used as the initial state of the variational circuit.


\subsection{QAOA ansatz}\label{subsec:qaoa}

In one sentence, QAOA is a short tunable quantum circuit whose angles are chosen so that the most likely measurement outcomes are the lowest-cost portfolios. The remainder of this subsection unpacks what \emph{short}, \emph{tunable}, and \emph{most likely} mean in practice.

\paragraph{Adiabatic intuition.}
QAOA \autocite{farhi2014qaoa} is a discretised, variational analogue of quantum adiabatic computation. The adiabatic theorem says that a system prepared in the ground state of an initial Hamiltonian and slowly evolved towards a final Hamiltonian stays in the instantaneous ground state. Taking $H_C$ from \cref{subsec:pauli} as the final Hamiltonian and the transverse-field mixer $H_M$ as the initial Hamiltonian, with ground state~\eqref{eq:plus-state}, turns combinatorial optimisation into ground-state preparation. The required evolution time can scale exponentially in $n$, so QAOA approximates it by $p$ short alternating steps generated by $H_C$ and $H_M$ and treats the step durations $(\gamma_k, \beta_k)$ as variational parameters. As $p \to \infty$ the ansatz recovers the exact adiabatic algorithm \autocite{zhou2018qaoa}.

The single-layer ($p = 1$) ansatz is
\begin{equation}
    |\psi(\gamma,\beta)\rangle =
    e^{-i \beta H_M}\,
    e^{-i \gamma H_C}\,
    |+\rangle^{\otimes n},
\end{equation}
where $e^{-i\gamma H_C}$ is the \emph{phase-separation} unitary (it phases each basis state by $e^{-i\gamma\, C(\boldsymbol{x})}$, encoding cost information into the amplitudes), and $e^{-i\beta H_M}$ is the \emph{mixing} unitary, which redistributes amplitude between bitstrings to enable transitions between candidate solutions.

\begin{equation}
    \underbrace{H^{\otimes n}}_{\text{superposition}}
    \longrightarrow
    \underbrace{e^{-i\gamma H_C}}_{\text{phase separation}}
    \longrightarrow
    \underbrace{e^{-i\beta H_M}}_{\text{mixing}}
    \longrightarrow
    \underbrace{\text{measure}}_{Z\text{-basis}}
\end{equation}

For depth $p > 1$, $p$ cost and $p$ mixer layers are alternated,
\begin{equation}\label{eq:multilayer}
    |\psi(\boldsymbol\gamma,\boldsymbol\beta)\rangle =
    \prod_{k=1}^{p}
    \left(
        e^{-i\beta_k H_M}\,
        e^{-i\gamma_k H_C}
    \right)
    |+\rangle^{\otimes n},
\end{equation}
with $2p$ variational parameters $(\gamma_1,\dots,\gamma_p,\beta_1,\dots,\beta_p)$.

\paragraph{Interference mechanism.}
The diagonal $e^{-i\gamma H_C}$ imprints the cost landscape onto the wavefunction without changing measurement probabilities. The non-diagonal $e^{-i\beta H_M}$ mixes amplitude between basis states; because $[H_C, H_M] \neq 0$, the two operations together produce non-trivial quantum interference. With the right angles, amplitude accumulates constructively on low-cost bitstrings and destructively on high-cost ones, concentrating measurement probability on near-optimal solutions. This is what distinguishes QAOA from classical heuristics such as simulated annealing or tabu search: amplitude flows non-locally across the cost landscape in superposition, whereas classical samplers visit one configuration at a time \autocite{giovagnoli_qaoa_intro}.

\paragraph{Hybrid quantum--classical loop.}
A classical optimiser minimises the energy expectation value
\begin{equation}\label{eq:Egb}
    E(\boldsymbol\gamma, \boldsymbol\beta) =
    \langle \psi(\boldsymbol\gamma,\boldsymbol\beta) |\, H_C\, | \psi(\boldsymbol\gamma,\boldsymbol\beta)\rangle.
\end{equation}
Since $H_C$ is diagonal in the computational basis with eigenvalues $C(\boldsymbol{x})$, this reduces to
\begin{equation}\label{eq:E-as-prob}
    E(\boldsymbol\gamma, \boldsymbol\beta) = \sum_{\boldsymbol{x}\in\{0,1\}^n} C(\boldsymbol{x})\, |\langle \boldsymbol{x} | \psi \rangle|^2,
\end{equation}
so the QAOA energy is a probability-weighted average of cost values. The circuit has $2p$ parameters and depth $O(p)$: the quantum device supplies a non-classical sampling primitive, while the parameter search sits on a classical CPU \autocite{tilly2022vqe}. The variational principle guarantees $E(\boldsymbol\gamma,\boldsymbol\beta) \geq E_{\text{opt}}$ for all angles, with equality as $p \to \infty$. Our classical optimiser is COBYLA with random multi-starts; see \cref{subsec:codestructure}.

\paragraph{Optimiser pathologies.}
The classical outer loop is the dominant practical bottleneck. Two failure modes are known. First, \emph{barren plateaus}: for sufficiently deep random parameterised circuits the variance of $\partial E / \partial\theta$ vanishes exponentially in $n$, so gradient-based or random-search methods need exponentially many samples to make progress \autocite{mcclean2018barren}. The transverse-field mixer ansatz studied here is, formally, in the regime where this prediction applies once $p$ is large; the warm-start prescription of \cref{subsec:warmstart} is one of the standard mitigations. Second, even outside the barren-plateau regime the angle space $(\boldsymbol\gamma, \boldsymbol\beta) \in \mathbb{R}^{2p}$ is non-convex, and a fixed random-multi-start budget covers it exponentially less densely as $p$ grows. \Cref{subsec:sp-depth-results,subsec:warmstart-results} report both effects empirically.


\subsection{XY-mixer: a constraint-preserving alternative}\label{subsec:xymixer}

The XY-mixer answers a simple question: instead of \emph{penalising} portfolios that pick the wrong number of assets, what if the algorithm physically \emph{cannot leave} the subspace of valid $K$-asset portfolios in the first place? Then the penalty in \eqref{eq:Cx} can be set to zero. The penalty $A(\sum_i x_i - K)^2$ in~\eqref{eq:Cx} enforces the budget only as $A \to \infty$. At finite $A$, infeasible bitstrings remain in the search space and may carry non-negligible amplitude after a finite-depth circuit. An alternative drops the penalty and uses a mixer that preserves Hamming weight by construction \autocite{mancilla2026constrained}. The \emph{XY-ring mixer} is
\begin{equation}\label{eq:HM-XY}
    H_M^{(XY)} = \tfrac{1}{2} \sum_{i=1}^{n} \bigl( \hat{X}_i \hat{X}_{i+1} + \hat{Y}_i \hat{Y}_{i+1} \bigr),
\end{equation}
with periodic boundary conditions ($i + 1$ taken mod $n$) and
\begin{equation}
    Y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}.
\end{equation}
The operator $\hat{X}_i \hat{X}_{i+1} + \hat{Y}_i \hat{Y}_{i+1}$ swaps $|01\rangle$ and $|10\rangle$ on neighbouring qubits while leaving $|00\rangle$ and $|11\rangle$ invariant, so it commutes with the Hamming-weight operator $\hat{N} = \sum_i \tfrac{1}{2}(I - \hat{Z}_i)$. If the initial state is a feasible Dicke state $|D^n_K\rangle$, the entire QAOA trajectory stays in the feasible subspace and the penalty $A$ becomes unnecessary.

The XY-mixer is hyperparameter-free but requires Dicke-state preparation and has more gates per layer than~\eqref{eq:HM-transverse}. In our statevector simulator the per-layer cost is dominated by a sparse \texttt{expm\_multiply} on a $2^n\times 2^n$ matrix, whereas the transverse-field mixer factorises into $n$ single-qubit rotations and is roughly an order of magnitude cheaper. The Dicke state $|D^n_K\rangle$, the equal superposition over all weight-$K$ bitstrings,
\begin{equation}\label{eq:dicke}
    |D^n_K\rangle \;=\; \frac{1}{\sqrt{\binom{n}{K}}} \sum_{\boldsymbol{x}:\,|\boldsymbol{x}|=K} |\boldsymbol{x}\rangle,
\end{equation}
is the symmetric ground state of $-H_M^{(XY)}$ in that subspace, and the preparation circuit of \textcite{bartschi2022dicke} runs in depth $O(n)$ on a fully connected device. \Cref{subsec:xymixer-results} benchmarks XY/Dicke against penalty/transverse-field at fixed $n$, $K$ and depth.


\subsection{Warm-started angle initialisation}\label{subsec:warmstart}

The variational landscape $E(\boldsymbol\gamma, \boldsymbol\beta)$ lives in $2p$ real dimensions and is non-convex even at $p=1$ (\cref{fig:landscape}). Drawing all $2p$ angles uniformly from $\mathcal{U}[0,2\pi]^{2p}$ at each depth treats the sweep as $p$ independent problems, so a fixed restart budget covers angle space exponentially less densely as $p$ grows. \textcite{zhou2018qaoa} noted that the optimal angles at depth $p$ are typically continuously related to those at $p-1$, and proposed seeding the depth-$p$ optimiser by appending a fresh layer to the depth-$(p-1)$ optimum,
\begin{equation}\label{eq:warmstart}
    (\boldsymbol\gamma_0^{(p)}, \boldsymbol\beta_0^{(p)})
    \;=\;
    \bigl((\boldsymbol\gamma^{\star,(p-1)}, \gamma_p^{\text{rand}}),\,
          (\boldsymbol\beta^{\star,(p-1)}, \beta_p^{\text{rand}})\bigr),
\end{equation}
followed by a short COBYLA refinement. Iterating from $p=1$ upwards turns the depth sweep into a single trajectory through cumulative $\mathbb{R}^{2p}$ angle space instead of $p$ independent ones. Any non-monotonicity in $r$ versus $p$ that comes from angle-space coverage (rather than ansatz limits) should then disappear, the empirical test of \cref{subsec:warmstart-results}. The prescription adds one layer per depth at no extra restart cost and is independent of the mixer, so it stacks with the XY-mixer of \cref{subsec:xymixer}.


\subsection{Metrics and validation}\label{subsec:metrics}

We track four diagnostics rather than a single number because no one of them captures both \emph{how close the expected energy is to the optimum} and \emph{how likely a measurement is to actually return the optimal bitstring}. The first two below are energy-based, the next two are probability-based, and we add the practitioner's Sharpe ratio so the QAOA output can be compared against the brute-force optimum on the metric an investor actually cares about.

\paragraph{Scaled approximation ratio.}
Let $E_{\text{opt}} = \min_{\boldsymbol{x}} C(\boldsymbol{x})$ and $E_{\text{worst}} = \max_{\boldsymbol{x}} C(\boldsymbol{x})$ denote the global minimum and maximum of the cost function, obtained by exhaustive enumeration. Following \textcite{farhi2014qaoa}, we define
\begin{equation}\label{eq:approxratio}
    r \;=\; \frac{E_{\text{worst}} - E(\boldsymbol\gamma^\star, \boldsymbol\beta^\star)}{E_{\text{worst}} - E_{\text{opt}}} \;\in\; [0,\,1],
\end{equation}
where $(\boldsymbol\gamma^\star, \boldsymbol\beta^\star)$ are the COBYLA-optimised angles. $r = 1$ means the optimum is recovered in expectation; an unbiased uniform sample gives $r = (E_{\text{worst}} - \overline{E}) / (E_{\text{worst}} - E_{\text{opt}})$, around $0.5$ for the canonical instance at $A=0.5$.

\paragraph{Relative gap.}
$E_{\text{worst}}$ is dominated by the budget penalty $A K^2$ and inflates the denominator of~\eqref{eq:approxratio}, so the scaled ratio compresses what can be a substantial absolute shortfall \autocite{zhou2018qaoa}. We also report the unscaled relative gap
\begin{equation}\label{eq:gaprel}
    \mathrm{gap}_{\text{rel}} \;=\; \frac{E(\boldsymbol\gamma^\star,\boldsymbol\beta^\star) - E_{\text{opt}}}{|E_{\text{opt}}|},
\end{equation}
which is zero at the optimum and unbounded above.

\paragraph{Top-1 success probability.}
The probability that a single measurement returns the true optimum,
\begin{equation}\label{eq:popt}
    p_{\text{opt}} \;=\; \bigl|\langle \boldsymbol{x}^\star | \psi(\boldsymbol\gamma^\star,\boldsymbol\beta^\star)\rangle\bigr|^2,
\end{equation}
with $\boldsymbol{x}^\star = \arg\min_{\boldsymbol{x}} C(\boldsymbol{x})$ the brute-force optimum.

\paragraph{Feasibility probability.}
The probability that a measurement yields a budget-feasible bitstring,
\begin{equation}\label{eq:pfeas}
    p_{\text{feas}} \;=\; \sum_{\boldsymbol{x}\,:\,\sum_i x_i = K} \bigl|\langle \boldsymbol{x} | \psi(\boldsymbol\gamma^\star,\boldsymbol\beta^\star)\rangle\bigr|^2,
\end{equation}
which is unity by construction under the XY-mixer of \cref{subsec:xymixer} and is a non-trivial diagnostic for the penalty mixer used here.

\paragraph{Sharpe ratio.}
For comparing candidate portfolios in financial terms alongside the QUBO cost, we report the equal-weighted Sharpe ratio of a selected basket $\boldsymbol{x}$ over the in-sample window,
\begin{equation}\label{eq:sharpe}
    \mathrm{Sharpe}(\boldsymbol{x}) \;=\; \frac{\boldsymbol{\mu}^\top \boldsymbol{x}}{\sqrt{\boldsymbol{x}^\top \boldsymbol{\Sigma}\, \boldsymbol{x}}},
\end{equation}
computed from the same daily-return moments. This is the metric a portfolio manager would actually care about; the QUBO cost $C(\boldsymbol{x})$ of \eqref{eq:Cx} is a $\lambda$-weighted proxy for it plus the budget penalty.

\paragraph{Validation strategy.}
At $n = 16$ the brute-force optimum is computable in $2^{16}\approx 6.5\times 10^4$ evaluations ($\sim 30$~ms in NumPy), so every QAOA run in \cref{section:result} is anchored against the exact answer. The QUBO$\to$Ising mapping of~\eqref{eq:hJ}--\eqref{eq:c} is also verified numerically: $H(\boldsymbol{z}) + c = C(\boldsymbol{x})$ to floating-point precision for every $|\boldsymbol{z}\rangle$, and the diagonal of $H_C$ in~\eqref{eq:HC} matches the brute-force cost vector. Further checks are in \cref{subsec:validation}.
