\subsection*{A. Notation and conventions}\label{subsec:app_notation}

Symbols are used consistently throughout the report, in line with \textcite{iso80000_2}. Vectors are typeset bold lower case ($\boldsymbol{x}$, $\boldsymbol\mu$), matrices bold upper case ($\boldsymbol\Sigma$, $Q$), and components carry an index ($x_i$, $\mu_i$, $\Sigma_{ij}$). Operators acting on the qubit Hilbert space carry a hat ($\hat{Z}_i$, $\hat{X}_i$); the cost and mixer Hamiltonians $H_C, H_M$ are written without hats because they are sums of hatted single-qubit operators and the typographical distinction is unambiguous in context. \Cref{tab:notation} collects every recurring symbol with its definition and the equation or section in which it is introduced.

\subsection*{F. Selected code listings}

The full source tree is available at \texttt{github.com/egil10/fys5419}. We reproduce three modules in full because they are the smallest non-trivial pieces of code that the report's empirical claims rest on, and the line counts are short enough that printing them here makes the report self-contained.

\paragraph{Hamming-weight-preserving XY-ring mixer.} The XY-ring mixer of \cref{eq:HM-XY} is built as a sparse $2^n \times 2^n$ matrix from the per-pair $(X_iX_j + Y_iY_j)$ contributions; the operator acts non-trivially only on basis states where bits $i$ and $j$ differ, and swaps them. The applicator then uses \texttt{scipy.sparse.linalg.expm\_multiply} to evaluate $\exp(-i\beta H_M^{(XY)})|\psi\rangle$ without ever materialising the dense exponential.

\begin{lstlisting}[language=Python,style=pythonappendix,caption={\texttt{xy\_mixer.py}: sparse XY-ring mixer and \texttt{expm\_multiply} applicator.},label={lst:xy_mixer}]
def _xy_pair_indices(n, i, j):
    # (1/2)(X_i X_j + Y_i Y_j) acts non-trivially only on basis states
    # where bits i and j differ, and swaps them (hopping term).
    dim = 1 << n
    bit_i = 1 << (n - 1 - i); bit_j = 1 << (n - 1 - j)
    rows, cols = [], []
    for k in range(dim):
        bi = (k >> (n - 1 - i)) & 1
        bj = (k >> (n - 1 - j)) & 1
        if bi != bj:
            rows.append(k); cols.append(k ^ bit_i ^ bit_j)
    return rows, cols, np.ones(len(rows))

def build_HM_xy(n, periodic=True):
    pairs = ([(i, (i + 1) % n) for i in range(n)] if periodic
             else [(i, i + 1) for i in range(n - 1)])
    rows, cols, data = [], [], []
    for (i, j) in pairs:
        r, c, d = _xy_pair_indices(n, i, j)
        rows.extend(r); cols.extend(c); data.extend(d)
    return 0.5 * sp.csr_matrix((data, (rows, cols)),
                               shape=(1 << n, 1 << n))

def apply_xy_mixer(psi, beta, H_M_xy):
    # exp(-i beta H) @ psi via Krylov; no dense exponential.
    return expm_multiply(-1j * beta * H_M_xy, psi)
\end{lstlisting}

\paragraph{Dicke initial state.} The equal superposition over weight-$K$ bitstrings is the symmetric ground state of $-H_M^{(XY)}$ in the constrained subspace. At the $n \leq 12$ sizes benchmarked we prepare it by direct enumeration; for $n \gg 20$ the asymptotically efficient depth-$O(n)$ circuit of \textcite{bartschi2022dicke} would be used instead.

\begin{lstlisting}[language=Python,style=pythonappendix,caption={\texttt{dicke.py}: direct-enumeration Dicke state prep on the $\binom{n}{K}$-dimensional weight-$K$ manifold.},label={lst:dicke}]
def dicke_state(n, K):
    # |D^n_K> = (1/sqrt(C(n,K))) * sum_{|x|=K} |x>
    if not (0 <= K <= n):
        raise ValueError(f"K={K} out of range [0, {n}]")
    psi = np.zeros(1 << n, dtype=complex)
    amp = 1.0 / np.sqrt(comb(n, K))
    for k in range(1 << n):
        if bin(k).count('1') == K:
            psi[k] = amp
    return psi
\end{lstlisting}

\paragraph{Exact MIP baseline via PuLP/CBC.} The same QUBO, but with the cardinality constraint imposed exactly and the variance term linearised by the standard McCormick--Glover construction \parencite{glover1975integerprog}.

\begin{lstlisting}[language=Python,style=pythonappendix,caption={\texttt{mip.py}: McCormick-linearised mixed-integer programme solved by COIN-OR CBC \parencite{forrest_cbc}.},label={lst:mip}]
def mip_exact(pf, time_limit=60.0, msg=False):
    import pulp
    n, K = pf.n, int(pf.K)
    prob = pulp.LpProblem("portfolio_mip", pulp.LpMinimize)
    x = [pulp.LpVariable(f"x_{i}", cat=pulp.LpBinary) for i in range(n)]
    # z_ij = x_i x_j (McCormick linearisation).
    z = {}
    for i in range(n):
        for j in range(i + 1, n):
            z_ij = pulp.LpVariable(f"z_{i}_{j}", lowBound=0, upBound=1)
            z[(i, j)] = z_ij
            prob += z_ij <= x[i]; prob += z_ij <= x[j]
            prob += z_ij >= x[i] + x[j] - 1
    # Hard cardinality constraint replaces the QUBO's A-penalty.
    prob += pulp.lpSum(x) == K
    # Objective: -mu^T x + lam * (sum Sigma_ii x_i + 2 sum_{i<j} Sigma_ij z_ij).
    linear = pulp.lpSum(-pf.mu[i] * x[i] for i in range(n))
    diag   = pulp.lpSum(pf.lam * pf.Sigma[i, i] * x[i] for i in range(n))
    off    = pulp.lpSum(2 * pf.lam * pf.Sigma[i, j] * z[(i, j)]
                        for i, j in z)
    prob += linear + diag + off
    prob.solve(pulp.PULP_CBC_CMD(msg=msg, timeLimit=time_limit))
    x_val = np.array([int(round(pulp.value(xi))) for xi in x])
    return SolverResult(name="mip_cbc", x=x_val, cost=pf.cost(x_val), ...)
